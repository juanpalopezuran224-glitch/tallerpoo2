10. Preguntas de comprensión

1. ¿Qué ventaja tiene dibujar el diagrama UML antes de escribir el código?

Permite organizar y visualizar cómo será la clase antes de programarla. Así es más fácil identificar sus atributos, métodos y relaciones, y se pueden evitar errores.

2. ¿A qué parte del código corresponde cada una de las tres divisiones del diagrama de clases?

La primera división corresponde al nombre de la clase, la segunda a los atributos y la tercera a los métodos de la clase.

3. ¿Cuál es la diferencia entre un comentario // y un bloque /** ... */ de Javadoc?

// sirve para escribir comentarios de una sola línea que no se ejecutan. /** ... */ se utiliza para documentar clases, métodos o atributos y permite generar documentación automática con Javadoc.

4. ¿Por qué es importante documentar el código en un equipo de trabajo?

Porque ayuda a que otros integrantes entiendan cómo funciona el código, puedan modificarlo o corregirlo más fácilmente y facilita el trabajo en equipo.
